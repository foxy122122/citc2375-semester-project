Inside client/css, create styles.css.
Link that stylesheet from the head of every HTML page:

<link rel="stylesheet" href="css/styles.css">

If a page is later moved into a subfolder, adjust the relative path rather than copying the stylesheet.
In styles.css, set a readable font family, default text color, background color, and line height on body.
Create a consistent site layout across all pages. Use the same site header and footer on every page, including the same site name/branding and navigation. Keep each page's page-specific h1 inside main. Create a reusable content-width class, such as .content-width, for the content inside the header and footer, and give it the same maximum width, horizontal auto margins, and padding used for main. The header and footer backgrounds may span the full browser width, but their content should align with the main page content.
Style h1, h2, and paragraph text so the hierarchy is obvious.
Create reusable classes for your collection items, such as .item-card, and apply the class to each of the 3 sample article elements.
Use the box model intentionally: add padding inside cards, visible spacing between cards, a border or other boundary, and an appropriate border radius if desired.
Style navigation links. Include an obvious hover/focus state so keyboard and mouse users can tell which link is active.
Style images so they do not overflow their container. A common starting point is max-width: 100% and height: auto.
Open both pages in the browser and make sure they share a consistent appearance.
