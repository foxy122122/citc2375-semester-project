-Create client/js/app.js.

-Link it near the end of the body of index.html using <script src="js/app.js"></script>.

-In app.js, create meaningful const variables for your project: project title, number of current sample items, a numeric value such as a rating/price/duration,
 and at least one boolean.

-Create at least one numeric calculation using arithmetic operators. The calculation must make sense for your topic (average, total, remaining amount, percentage,
 score, etc.).

Create at least one string using a template literal so project data is inserted into a sentence.

-Create an if/else decision based on project data. Example: display a different console message when the number of sample items is at least 3.

-Use console.log to display the project summary, the calculation result, and the conditional result.

Open the deployed or local site, press F12, open the Console, and verify that your messages appear without JavaScript errors.

-Do not use DOM APIs such as document.querySelector in this checkpoint. Those will be introduced later.
