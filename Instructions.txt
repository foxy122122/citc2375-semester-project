Step 5: Create the ItemCard component

Create ItemCard.jsx so it receives one item through props, displays its information, and includes the favorite control from Checkpoint 9.

Example:

export default function ItemCard({
    item,
    isFavorite,
    onToggleFavorite
}) {
    return (
        <article>
            <h2>{item.name}</h2>
            <p>{item.description}</p>

            <button
                type="button"
                aria-pressed={isFavorite}
                onClick={() => onToggleFavorite(item.id)}
            >
                {isFavorite ? "★ Favorite" : "☆ Add to favorites"}
            </button>
        </article>
    );
}

Adapt this component to display the actual properties from your item objects. Your favorite control must update when clicked.
Step 6: Create the ItemList component

Create ItemList.jsx so it receives the items to display and uses map() to render an ItemCard for each item.

Example:

import ItemCard from './ItemCard.jsx';

export default function ItemList({
    items,
    favoriteIds,
    onToggleFavorite
}) {
    if (items.length === 0) {
        return <p>No matching items were found.</p>;
    }

    return (
        <section>
            {items.map(item => (
                <ItemCard
                    key={item.id}
                    item={item}
                    isFavorite={favoriteIds.includes(item.id)}
                    onToggleFavorite={onToggleFavorite}
                />
            ))}
        </section>
    );
}

Each item must use its unique ID as the React key. Preserve the no-results behavior from Checkpoint 9.
Step 7: Assemble the application in App.jsx

In App.jsx, import useState, your components, and your exported item array. Use React state to track the selected category and favorite item IDs.

A simplified example is shown below:

import { useState } from 'react';
import Header from './components/Header.jsx';
import ItemList from './components/ItemList.jsx';
import { items } from './data.js';
import './App.css';

export default function App() {
    const [selectedCategory, setSelectedCategory] =
        useState(() => {
            return localStorage.getItem(
                'myProject.selectedCategory'
            ) || 'All';
        });

    const [favoriteIds, setFavoriteIds] =
        useState(() => {
            const saved = localStorage.getItem(
                'myProject.favoriteIds'
            );

            return saved ? JSON.parse(saved) : [];
        });

    function handleCategoryChange(event) {
        const category = event.target.value;

        setSelectedCategory(category);
        localStorage.setItem(
            'myProject.selectedCategory',
            category
        );
    }

    function handleToggleFavorite(itemId) {
        const updated = favoriteIds.includes(itemId)
            ? favoriteIds.filter(id => id !== itemId)
            : [...favoriteIds, itemId];

        setFavoriteIds(updated);

        localStorage.setItem(
            'myProject.favoriteIds',
            JSON.stringify(updated)
        );
    }

    const filteredItems =
        selectedCategory === 'All'
            ? items
            : items.filter(
                item => item.category === selectedCategory
            );

    return (
        <>
            <Header />

            <main>
                <label htmlFor="category-filter">
                    Category
                </label>

                <select
                    id="category-filter"
                    value={selectedCategory}
                    onChange={handleCategoryChange}
                >
                    <option value="All">
                        All categories
                    </option>
                </select>

                <ItemList
                    items={filteredItems}
                    favoriteIds={favoriteIds}
                    onToggleFavorite={handleToggleFavorite}
                />
            </main>
        </>
    );
}

This is only an example. Use your own categories, storage keys, item properties, and markup.

Use the same localStorage keys from Checkpoint 9 when possible so previously saved preferences continue to work.

You do not need useEffect or React Router for this checkpoint.

npm run dev

Verify that:
